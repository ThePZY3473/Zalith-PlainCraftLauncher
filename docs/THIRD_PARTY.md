# 第三方组件与许可

本项目在 Zalith Launcher 2 的基础上二次开发。此页记录继承自上游或在本项目中使用的第三方组件、署名与许可证入口，不是某个 APK 的完整物料清单。实际使用范围和许可条款以该构建所用的版本、随附声明及许可证正文为准。
